**1. Create `apps/web/src/hooks/use-recurring.ts`:**

Follow the pattern from `use-transactions.ts` and `use-loans.ts`. Import `trpc` from `@/utils/trpc`, `useQuery`, `useMutation`, `useQueryClient` from `@tanstack/react-query`, `toast` from `sonner`.

Create and export:

- `useRecurringRules()`: Calls `trpc.recurring.list.queryOptions()` with `useQuery`. Returns `{ rules, isLoading, error, refetch }`.

- `useCreateRecurringRule()`: Mutation hook using `trpc.recurring.create.mutationOptions()`. On success: toast "Recurring rule created", invalidate recurring.list queries. On error: toast "Failed to create recurring rule".

- `useUpdateRecurringRule()`: Mutation hook using `trpc.recurring.update.mutationOptions()`. On success: toast "Recurring rule updated", invalidate recurring.list and recurring.getById queries. On error: toast "Failed to update recurring rule".

- `useDeleteRecurringRule()`: Mutation hook using `trpc.recurring.delete.mutationOptions()`. On success: toast "Recurring rule deleted", invalidate recurring.list. On error: toast "Failed to delete recurring rule". Optimistically remove from list cache.

- `useTodayGenerated()`: Calls `trpc.recurring.todayGenerated.queryOptions()` with `useQuery`. Returns `{ count, isLoading }`. This is used by the dashboard banner.

**2. Create `apps/web/src/components/recurring/recurring-form.tsx`:**

A modal/dialog form for creating and editing recurring rules. Use the existing form patterns (TanStack Form + Zod validation, shadcn Dialog).

Props: `{ open: boolean; onOpenChange: (open: boolean) => void; editingRule?: RecurringRuleData | null }`

Form fields (in order):
1. **Type**: Toggle/select between "Expense" (default) and "Income". Use radio buttons or segmented control.
2. **Description**: Text input, optional. Placeholder "e.g., Netflix subscription"
3. **Amount**: Money input following existing pattern (string input, validated as money).
4. **Frequency**: Select dropdown with options: Daily, Weekly, Biweekly, Monthly, Yearly.
5. **Day of Week** (shown only when frequency is WEEKLY or BIWEEKLY): Select dropdown with Sunday-Saturday (values 0-6).
6. **Day of Month** (shown only when frequency is MONTHLY): Number input 1-31. Default to today's day-of-month.
7. **Start Date**: Date picker. Default to today.
8. **End Condition**: Three radio options:
   - "Run forever" (default) — no endDate or maxOccurrences
   - "End on date" — shows a date picker for endDate
   - "After N occurrences" — shows a number input for maxOccurrences
9. **Tags**: Multi-tag selector (reuse the tag selection pattern from the transaction form).

On submit:
- If editing, call `useUpdateRecurringRule().mutate()`
- If creating, call `useCreateRecurringRule().mutate()`
- Close dialog on success

Use `useForm` from `@tanstack/react-form` with the zod adapter (follow existing form patterns in the codebase).

**3. Create `apps/web/src/components/recurring/recurring-list.tsx`:**

A table/list view component. Use Tailwind utility classes for table styling (follow existing patterns; check if shadcn Table component is available, if so use it).

Table columns:
1. **Status indicator**: Small colored dot or icon — green for ACTIVE, amber for PAUSED. Per CONTEXT.md: "Paused" badge should be prominent.
2. **Description/Name**: The rule's description. If none, show frequency + amount as fallback label.
3. **Type indicator**: Subtle color or icon — green arrow up for INCOME, red arrow down for EXPENSE. Per CONTEXT.md: visual indicator (color/icon) for income vs expense.
4. **Amount**: Formatted with currency using `formatCents` from `@/lib/format.ts`.
5. **Frequency**: Human-readable label (e.g., "Monthly", "Every 2 weeks", "Daily").
6. **Next Date**: The nextOccurrenceDate formatted as a short date (e.g., "Feb 15, 2026"). Show "Paused" if status is PAUSED.
7. **Tags**: Show tag pills/badges (colored dots with names), same as transaction list.

Each row should be clickable (opens edit form) or have an edit button.

Sort default: by nextOccurrenceDate ascending (soonest first), with PAUSED rules at the bottom.
