Create apps/web/src/hooks/use-tags.ts with tRPC-powered hooks:

**useTags():**
- Call trpc.tag.list.useQuery()
- Return { tags, isLoading, error, refetch }
- Tags are automatically filtered to user's active tags by API

**useCreateTag():**
- Use useMutation with trpc.tag.create
- Implement optimistic update:
  1. onMutate: Cancel queries, get snapshot, add temp tag to cache
  2. onError: Rollback to snapshot, show error toast via sonner
  3. onSettled: Invalidate tag.list query
  4. onSuccess: Show success toast "Tag created"
- Use temp ID format: `temp-${Date.now()}-${Math.random().toString(36).slice(2)}`

**useUpdateTag():**
- Use useMutation with trpc.tag.update
- Implement optimistic update similar to create
- onSuccess: Show success toast "Tag updated"

**useDeleteTag():**
- Use useMutation with trpc.tag.delete
- Implement optimistic update (remove from cache)
- onSuccess: Show success toast "Tag deleted"
- Note: This is soft delete - API sets isActive=false

Import trpc from @/utils/trpc, toast from sonner, useQueryClient from @tanstack/react-query.

Query key pattern: Use trpc helper for query keys, or manually construct as ["tag", "list"].
