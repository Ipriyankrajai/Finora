cd apps/web && bun add superjson react-colorful date-fns

Update apps/web/src/utils/trpc.ts to add superjson transformer:

1. Import superjson at top of file
2. Add transformer: superjson to httpBatchLink config
3. This is CRITICAL - without this, BigInt fields from Phase 2 API will cause serialization errors

Key implementation:
```typescript
import superjson from "superjson";

const trpcClient = createTRPCClient<AppRouter>({
  links: [
    httpBatchLink({
      url: "/api/trpc",
      transformer: superjson, // ADD THIS LINE
      fetch(url, options) {
        return fetch(url, {
          ...options,
          credentials: "include",
        });
      },
    }),
  ],
});
```

Also create apps/web/src/lib/format.ts with date/money formatting utilities:
- formatDate(date: Date): string - formats as "MMM d, yyyy"

- formatRelativeDate(date: Date): string - "Today", "Yesterday", or formatted date
- formatCents(cents: bigint | number): string - formats cents as "$1,234.56"
