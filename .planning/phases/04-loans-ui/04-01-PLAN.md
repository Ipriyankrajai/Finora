**useLoans():**
- Call trpc.loan.list via useQuery(trpc.loan.list.queryOptions())
- Return { loans: LoanWithBalance[], isLoading, error, refetch }
- Sort loans by balanceCents descending (highest first per CONTEXT.md)

**useLoan(id: string):**
- Call trpc.loan.getById via useQuery(trpc.loan.getById.queryOptions({ id }))
- Return full loan with payments and projection
- Handle loading and error states

**useCreateLoan():**
- Use useMutation with trpc.loan.create.mutationOptions()
- Optimistic update: Cancel queries, snapshot, add temp loan to cache
- Use predicate-based cache invalidation matching "loan" AND "list" (like transactions)
- onSuccess: toast.success("Loan created")
- onError: Rollback, toast.error("Failed to create loan")
- onSettled: Invalidate loan.list queries

**useUpdateLoan():**
- Similar pattern to useCreateLoan
- Optimistically update loan in cache
- onSuccess: toast.success("Loan updated")

**useDeleteLoan():**
- Optimistically remove from cache
- onSuccess: toast.success("Loan deleted")

Use predicate-based query invalidation pattern from use-transactions.ts:
```typescript
predicate: (query) =>

  query.queryKey[0].includes("list")
```

Auto-calculate payment when principal, rate, and term change:
```typescript
// PMT formula: P * (r * (1+r)^n) / ((1+r)^n - 1)
const calculateMonthlyPayment = (principal: number, annualRate: number, termMonths: number) => {
  const monthlyRate = annualRate / 100 / 12;
  if (monthlyRate === 0) return principal / termMonths;
  const x = Math.pow(1 + monthlyRate, termMonths);
  return (principal * x * monthlyRate) / (x - 1);
};
```

Use useEffect to update calculated payment when inputs change.
