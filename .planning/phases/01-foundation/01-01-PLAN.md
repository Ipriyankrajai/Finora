<task type="auto">
  <name>Task 1: Create finance.prisma with all models</name>
  <files>packages/db/prisma/schema/finance.prisma</files>
  <action>
Create `packages/db/prisma/schema/finance.prisma` with:

**TransactionType enum:**
- INCOME, EXPENSE

**InterestType enum:**
- SIMPLE, COMPOUND (for loan interest calculation method)

**Transaction model:**
- id: String @id @default(cuid())
- userId: String (FK to User)
- type: TransactionType
- amountCents: BigInt (stored as integer cents)
- date: DateTime @db.Timestamptz(3)
- description: String? (optional notes)
- currencyCode: String @default("USD")
- linkedLoanPaymentId: String? (optional link back to loan payment that created this)
- createdAt/updatedAt with @db.Timestamptz(3)
- Relations: user User, tags TransactionTag[], linkedLoanPayment LoanPayment?
- Indexes: @@index([userId, date]), @@index([userId, type, date])
- Map: @@map("transaction")

**Tag model:**
- id: String @id @default(cuid())
- userId: String (FK to User)
- name: String
- color: String (hex color like #FF5733)
- isActive: Boolean @default(true) (soft delete)
- createdAt/updatedAt with @db.Timestamptz(3)
- Relations: user User, transactions TransactionTag[]
- Unique: @@unique([userId, name])
- Index: @@index([userId, isActive])
- Map: @@map("tag")

**TransactionTag junction model:**
- transactionId: String (FK to Transaction, onDelete: Cascade)
- tagId: String (FK to Tag, onDelete: Cascade)
- assignedAt: DateTime @default(now()) @db.Timestamptz(3)
- Composite PK: @@id([transactionId, tagId])
- Index: @@index([tagId])
- Map: @@map("transaction_tag")

**Loan model:**
- id: String @id @default(cuid())
- userId: String (FK to User)
- name: String (e.g., "Car Loan", "Mortgage")
- interestType: InterestType @default(COMPOUND)
- principalCents: BigInt (original loan amount)
- annualRatePercent: Float (e.g., 6.5 for 6.5%)
- termMonths: Int
- monthlyPaymentCents: BigInt (required payment)
- currencyCode: String @default("USD")
- startDate: DateTime @db.Timestamptz(3)
- createdAt/updatedAt with @db.Timestamptz(3)
- Relations: user User, payments LoanPayment[]
- Index: @@index([userId])
- Map: @@map("loan")

**LoanPayment model:**
- id: String @id @default(cuid())
- loanId: String (FK to Loan, onDelete: Cascade)
- amountCents: BigInt (total payment)
- principalCents: BigInt (portion reducing principal)
- interestCents: BigInt (portion paying interest)
- lateFeeCents: BigInt @default(0) (late fees if any)
- isExtra: Boolean @default(false) (extra payment flag)
- paidAt: DateTime @db.Timestamptz(3)
- linkedTransactionId: String? @unique (link to auto-created expense transaction)
- createdAt/updatedAt with @db.Timestamptz(3)
- Relations: loan Loan, linkedTransaction Transaction?
- Index: @@index([loanId, paidAt])
- Map: @@map("loan_payment")

**Important patterns from RESEARCH.md:**
- Use BigInt for all money fields (safety margin over Int)
- Use @db.Timestamptz(3) for all DateTime fields (timezone preservation)
- Composite indexes match common query patterns (userId + date)
- Soft delete via isActive for Tags only (per CONTEXT.md decisions)
