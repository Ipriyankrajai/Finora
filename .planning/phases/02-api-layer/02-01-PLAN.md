  <files>

  <action>
Create packages/api/src/schemas/common.ts with:
- cuidInput: z.string().cuid() for ID validation
- Reusable patterns for other routers

Create packages/api/src/schemas/tag.ts with:
- createTagInput: { name: string (1-50 chars, trimmed), color: hex color regex }
- updateTagInput: { id: cuid, name?: string, color?: hex }
- deleteTagInput: { id: cuid }

Create packages/api/src/routers/tag.ts with protectedProcedure:

1. **list**: Query returning user's active tags ordered by name
   - Filter: userId = ctx.session.user.id, isActive = true
   - Order: name asc

2. **create**: Mutation creating tag with userId from session
   - Validate name/color via Zod schema
   - Set userId from ctx.session.user.id

3. **update**: Mutation updating tag name/color
   - Find tag by id first
   - If not found: throw NOT_FOUND
   - If userId mismatch: throw UNAUTHORIZED (per CONTEXT.md)
   - Only update provided fields

4. **delete**: Mutation soft-deleting tag
   - Find tag by id first
   - If not found: throw NOT_FOUND
   - If userId mismatch: throw UNAUTHORIZED
   - Set isActive = false (soft delete per Phase 1 schema)

Update packages/api/src/routers/index.ts:
- Import and add tagRouter to appRouter

Error format per CONTEXT.md:
```typescript
throw new TRPCError({
  code: "NOT_FOUND",
  message: "Tag not found", // User-friendly
});
```
