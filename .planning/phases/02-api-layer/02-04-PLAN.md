**summary** query: One combined endpoint per CONTEXT.md decision

1. **Calculate date boundaries**:
   ```typescript
   const now = new Date();
   const monthStart = new Date(now.getFullYear(), now.getMonth(), 1);
   const monthEnd = new Date(now.getFullYear(), now.getMonth() + 1, 0, 23, 59, 59, 999);
   ```

2. **Monthly summary** (income/expense/net):
   - Fetch transactions for current month
   - Sum INCOME and EXPENSE separately
   - Calculate net = income - expense
   - Use Prisma groupBy or aggregate, or fetch and reduce in code

3. **Top spending tags** (top 5 + "Other"):
   - Per CONTEXT.md: Return top 5 tags with spending, group remainder as "Other"
   - Use raw SQL for performance (as shown in RESEARCH.md):
   ```typescript
   const spendingByTag = await ctx.db.$queryRaw<Array<{
     tagId: string;
     tagName: string;
     tagColor: string;
     totalCents: bigint;
   }>>`
     SELECT
       t.id as "tagId",
       t.name as "tagName",
       t.color as "tagColor",
       COALESCE(SUM(txn."amountCents"), 0) as "totalCents"
     FROM tag t
     LEFT JOIN transaction_tag tt ON t.id = tt."tagId"
     LEFT JOIN transaction txn ON tt."transactionId" = txn.id
       AND txn.type = 'EXPENSE'
       AND txn.date >= ${monthStart}
       AND txn.date <= ${monthEnd}
     WHERE t."userId" = ${userId} AND t."isActive" = true
     GROUP BY t.id, t.name, t.color
     ORDER BY "totalCents" DESC
     LIMIT 6
   `;
   ```
   - Return top 5 as topTags
   - Sum remainder as otherTagsTotal

4. **Loan overview**:
   - Fetch all user loans with payments
   - For each loan:
     - Calculate balance from payments
     - Calculate total interest paid
     - Use projectPayoff for projections
   - Return array of loan summaries

5. **Return combined response**:
   ```typescript
   return {
     monthlySummary: { incomeCents, expenseCents, netCents },
     topTags: spendingByTag.slice(0, 5),
     otherTagsTotal: /* sum of tags beyond top 5 */,
     loanOverview: /* loan summaries */,
   };
   ```
