Create packages/api/src/routers/loan.ts with protectedProcedure:

Import from Phase 1:
```typescript
import { projectPayoff } from "../lib/calculations";
import { displayToCents, centsToDisplay } from "../lib/money";
```

1. **list**: Query returning user's loans with summary
   - Filter: userId = ctx.session.user.id
   - Include payments for balance calculation
   - For each loan, calculate:
     - balanceCents: principalCents - sum(payments.principalCents)
     - totalInterestPaidCents: sum(payments.interestCents)
   - Order by createdAt desc

2. **getById**: Query returning single loan with full details
   - Include payments ordered by paidAt desc
   - Calculate current balance from payments
   - Use projectPayoff() for remaining projections:
     - monthsRemaining
     - totalInterestRemainingCents
     - projectedPayoffDate
   - Throw NOT_FOUND if not exists
   - Throw UNAUTHORIZED if userId mismatch

3. **create**: Mutation creating loan
   - Convert principal and monthlyPayment to cents
   - Set userId from session
   - Return created loan

4. **update**: Mutation updating loan
   - Check ownership (find first, verify userId)
   - Convert money fields to cents if provided
   - Return updated loan

5. **delete**: Mutation deleting loan
   - Check ownership
   - Hard delete (cascade deletes payments)

6. **addPayment**: Mutation logging a payment
   - Verify loan exists and user owns it
   - Calculate principal/interest split:
     ```typescript
     // Get current balance
     const payments = await ctx.db.loanPayment.findMany({
       where: { loanId: loan.id },
       select: { principalCents: true },
     });
     const paidPrincipal = payments.reduce((sum, p) => sum + p.principalCents, 0n);
     const currentBalance = loan.principalCents - paidPrincipal;

     // Calculate interest for this payment
     const monthlyRate = loan.annualRatePercent / 100 / 12;
     const interestCents = roundCents(Number(currentBalance) * monthlyRate);
     const principalCents = BigInt(input.amountCents) - interestCents;
     ```
   - Create LoanPayment with split amounts
   - Return created payment

7. **deletePayment**: Mutation removing a payment
   - Verify payment exists
   - Verify user owns the loan (join through loanId)
   - Hard delete

Update packages/api/src/routers/index.ts:
- Import and add loanRouter to appRouter
