     ```typescript
     export const spendingTrendInput = z.object({
       granularity: z.enum(["weekly", "daily"]),
       months: z.number().int().min(1).max(12).default(3),
     });
     ```
   - Add output type for spending trend data point

2. Add `getSpendingTrend` procedure to `packages/api/src/routers/dashboard.ts`:
   - Input: `{ granularity: "weekly" | "daily", months: number }`
   - Calculate date range: `now` back to `months` months ago
   - Query transactions in date range for current user
   - Group by date period (week start for weekly, day for daily)
   - For weekly: use date-fns `startOfWeek` to group
   - For daily: group by date directly
   - Return array of:
     ```typescript
     { date: Date, incomeCents: bigint, expenseCents: bigint }
     ```
   - Use JavaScript aggregation (not raw SQL) since data volume is manageable
   - Use date-fns for date calculations: eachWeekOfInterval, eachDayOfInterval, startOfWeek, format

3. Implementation approach:
   - Fetch all transactions in range
   - Create a Map keyed by period (ISO date string for day, week start ISO for week)
   - Initialize all periods with 0 income/expense
   - Iterate transactions and accumulate into appropriate bucket
   - Convert Map to sorted array
  </action>
